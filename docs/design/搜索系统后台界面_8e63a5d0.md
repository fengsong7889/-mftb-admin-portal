# 搜索系统后台管理界面

## 技术方案
- **框架**: Vue3 + Vite + TypeScript
- **UI组件库**: Element Plus
- **图表**: ECharts (搜索统计可视化)
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **数据**: 前端 Mock 模拟数据

## 实施任务

### Task 1: 项目初始化
- 使用 Vite 创建 Vue3 + TypeScript 项目
- 安装 Element Plus、Vue Router、Pinia、ECharts 依赖
- 配置 Element Plus 按需引入

### Task 2: 布局与路由搭建
- 创建 AdminLayout 侧边栏布局（左侧导航 + 顶部栏 + 内容区）
- 配置 Vue Router 路由表，包含所有页面路由
- 侧边栏菜单对应四大功能模块

### Task 3: 仪表盘概览页 (Dashboard)
- 统计卡片：今日搜索量、索引文档数、平均响应时间、搜索成功率
- 搜索趋势折线图（近7天）
- 热门搜索词 TOP10
- 最近搜索日志列表

### Task 4: 索引数据管理模块
- **索引列表页**: 表格展示索引名称、文档数、字段数、状态、更新时间，支持搜索筛选、新建/删除索引
- **索引详情页**: 字段配置（字段名、类型、是否可搜索、是否可排序）、索引重建、数据预览

### Task 5: 搜索规则配置模块
- **权重配置**: 不同字段的搜索权重调整，滑块+输入框
- **同义词管理**: 同义词组增删改查，支持批量导入
- **停用词管理**: 停用词列表管理，支持批量添加
- **排序规则**: 默认排序策略配置（相关度/时间/自定义）

### Task 6: 搜索日志与统计模块
- **搜索日志**: 日志列表（搜索词、用户、结果数、耗时、时间），支持筛选和分页
- **统计分析**: 搜索量趋势图、搜索词云、零结果率、点击率分析、响应时间分布

### Task 7: 搜索效果测试模块
- 搜索输入框 + 实时结果展示
- 结果列表展示（标题、摘要、来源、得分）
- 支持切换不同规则配置对比搜索结果
- 搜索结果评分与反馈

### Task 8: Mock数据与交互完善
- 创建完整的模拟数据
- 所有页面交互逻辑串联
- 细节打磨（加载状态、空状态、操作反馈）
