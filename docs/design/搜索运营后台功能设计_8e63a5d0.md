# 搜索运营后台 - 菜单功能设计方案

## 整体菜单架构

```
搜索运营后台
├── 搜索概览 (Dashboard)
├── 底纹词管理
│   ├── 底纹词列表
│   ├── 新建底纹词
│   └── 底纹词预览
├── 热搜词管理
│   ├── 热搜词配置
│   ├── 热搜词审核
│   └── 热搜词报表
├── 频道管理
│   ├── 频道列表
│   └── 频道配置
├── 商户管理
│   ├── 商户列表
│   └── 商户热搜词申请
├── 数据分析
│   ├── 搜索量趋势
│   ├── 底纹词效果分析
│   ├── 热搜词转化分析
│   └── 搜索漏斗
└── 系统设置
    ├── 敏感词管理
    └── 搜索规则配置
```

---

## 模块一：底纹词管理

### 1.1 底纹词列表页
- 表格展示：底纹词文本、类型(文本/链接/商户)、所属频道、投放优先级、投放时段、状态(启用/停用/已过期)、创建时间
- 筛选条件：频道(全部/大首页/外卖/超市/团购)、类型、状态、时间范围
- 操作：编辑、启用/停用、复制、删除、拖拽排序
- 批量操作：批量启用、批量停用、批量删除

### 1.2 新建/编辑底纹词页
- 基础信息：
  - 底纹词文本(必填，限20字)
  - 类型选择：纯文本 / 外部链接 / 内部页面 / 跳转商户
  - 若选"外部链接"：URL输入框
  - 若选"跳转商户"：商户选择器(搜索商户ID/名称)
- 投放配置：
  - 投放频道(多选)：大首页 / 外卖频道 / 超市频道 / 团购频道
  - 投放时段：支持定时投放(起止日期+时间段)
  - 展示频次：每用户每日展示N次
  - 优先级：1-10级数字排序
- 展示配置：
  - 文字颜色
  - 左侧图标(可选)
  - 右侧标签(如"热门"、"推荐"、"限时")
- 高级配置：
  - 关联热搜词(点击底纹词自动填充热搜词)
  - AB测试分组

### 1.3 底纹词预览页
- 四频道手机模拟器：大首页/外卖/超市/团购 搜索框实时预览
- 支持切换不同底纹词预览效果
- 支持不同设备尺寸预览(iPhone/Android)

## 模块二：热搜词管理

### 2.1 热搜词配置页
- 手动配置区：
  - 表格：排名、热搜词文本、类型(系统采集/人工配置/商户申请)、所属频道、标签(热/新/爆/荐)、链接/商户、投放时段、状态
  - 新建热搜词：文本、频道(多选)、标签选择、类型(纯文本/链接/商户)、链接/商户选择、投放时段、优先级
  - 批量导入：支持Excel模板批量导入
- 系统采集区(自动)：
  - 展示系统自动统计的搜索热词(用户真实搜索行为)
  - 运营可一键采纳为配置热搜词
  - 展示搜索量、环比变化、首次出现时间

### 2.2 热搜词审核页
- 商户提交的付费热搜词申请
- 表格：申请商户、热搜词文本、申请频道、投放时段、出价、申请时间、审核状态
- 操作：通过、拒绝(填写原因)、退回修改
- 审核流程：商户提交 -> 运营审核 -> 自动上线

### 2.3 热搜词报表页
- 热搜排行榜：实时/日/周/月维度的热搜词TOP榜单
- 各频道热搜对比：大首页 vs 外卖 vs 超市 vs 团购
- 热搜词趋势图：单个热搜词搜索量随时间变化的折线图
- 热搜词关联分析：搜索某热词后用户还搜了什么

---

## 模块三：频道管理

### 3.1 频道列表
- 四大频道卡片展示：大首页、外卖、超市、团购
- 每个频道显示：当前底纹词数量、热搜词数量、今日搜索量、配置状态

### 3.2 频道配置
- 频道基本信息：名称、描述、图标
- 搜索框配置：搜索框样式、搜索建议数量、历史搜索保留天数
- 默认配置：默认排序规则、默认筛选条件
- 频道特色功能：外卖频道的"附近商户"、超市频道的"促销标签"等

---

## 模块四：商户管理

### 4.1 商户列表
- 表格：商户名称、商户ID、行业分类、搜索曝光量、搜索点击量、关联底纹词数、关联热搜词数、状态
- 筛选：行业、搜索量范围、是否有付费搜索位
- 操作：查看详情、搜索配置、暂停搜索

### 4.2 商户热搜词申请
- 商户申请列表(与热搜词审核联动)
- 商户搜索效果卡片：曝光量、点击量、转化率、花费

---

## 模块五：数据分析

### 5.1 搜索量趋势
- 整体搜索量折线图(支持日/周/月)
- 各频道搜索量对比
- 搜索时段热力图(24小时 x 7天)

### 5.2 底纹词效果分析
- 底纹词曝光量、点击量、点击率(CTR)趋势
- 各底纹词效果对比排行
- 底纹词类型效果对比(纯文本 vs 链接 vs 商户)
- 频道维度分析

### 5.3 热搜词转化分析
- 热搜词搜索量趋势
- 热搜词 -> 点击 -> 下单 转化漏斗
- 付费热搜词 vs 自然热搜词效果对比
- 热搜词ROI分析(针对商户付费热搜)

### 5.4 搜索漏斗
- 完整漏斗：搜索框曝光 -> 输入搜索词 -> 展示结果 -> 点击结果 -> 下单
- 各频道漏斗对比
- 流失环节分析

## 实现任务

### Task 1: 重构路由和侧边栏菜单
- 更新 `src/router/index.ts` 路由表，新增上述所有路由
- 更新 `src/layouts/AdminLayout.vue` 侧边栏菜单

### Task 2: 底纹词管理模块(3个页面)
- `src/views/hint-text/HintTextList.vue` - 底纹词列表(表格+筛选+批量操作)
- `src/views/hint-text/HintTextEdit.vue` - 新建/编辑底纹词(表单+商户选择器+频道多选)
- `src/views/hint-text/HintTextPreview.vue` - 底纹词预览(手机模拟器)

### Task 3: 热搜词管理模块(3个页面)
- `src/views/hot-search/HotSearchConfig.vue` - 热搜词配置(手动配置+系统采集+批量导入)
- `src/views/hot-search/HotSearchAudit.vue` - 热搜词审核(审核列表+通过/拒绝流程)
- `src/views/hot-search/HotSearchReport.vue` - 热搜词报表(排行榜+趋势图+关联分析)

### Task 4: 频道管理模块(2个页面)
- `src/views/channel/ChannelList.vue` - 频道列表(4频道卡片+统计数据)
- `src/views/channel/ChannelConfig.vue` - 频道配置(搜索框配置+默认规则)

### Task 5: 商户管理模块(2个页面)
- `src/views/merchant/MerchantList.vue` - 商户列表(搜索维度数据表格)

### Task 6: 数据分析模块(4个页面)
- `src/views/analytics/SearchTrend.vue` - 搜索量趋势(折线图+时段热力图)
- `src/views/analytics/HintEffect.vue` - 底纹词效果分析(CTR+对比)

- `src/views/analytics/SearchFunnel.vue` - 搜索漏斗(多步骤漏斗图)

### Task 7: 系统设置模块(2个页面)
- `src/views/settings/SensitiveWords.vue` - 敏感词管理
- `src/views/settings/SearchRuleSettings.vue` - 搜索规则配置

### Task 8: Mock数据完善
- 为所有新模块创建完整的模拟数据 `src/mock/`
